# Buses API and Angular screen

ADMIN-only bus management at `/buses`, backed by `/api/v1/buses`. Start either [local mode](../README.md#run-locally); [demo buses](../README.md#optional-demo-buses) are optional.

## API contract

| Method | Path | Success |
|---|---|---|
| GET | `/api/v1/buses` | 200, paginated list |
| POST | `/api/v1/buses` | 201, bus and relative `Location` header |
| GET | `/api/v1/buses/{id}` | 200, bus |
| PUT | `/api/v1/buses/{id}` | 200, updated bus |
| DELETE | `/api/v1/buses/{id}?version={version}` | 204 |

Create body:

```json
{ "registrationNumber": "DEMO-123", "capacity": 40, "active": true }
```

PUT replaces all editable fields and additionally requires `version` from the latest response. Responses contain `id`, `registrationNumber`, `capacity`, `active` and `version`.

| Field | Rules |
|---|---|
| `registrationNumber` | Required, 1–32 characters; no surrounding Unicode whitespace or control characters; exact, case-sensitive uniqueness |
| `capacity` | Required integer, 1–2,147,483,647; decimals and numeric strings rejected |
| `active` | Required boolean; `false` retains the record as inactive |
| `id` | Positive, generated by PostgreSQL; rejected in write bodies |
| `version` | Server-managed; required non-negative value for PUT/DELETE, rejected on create |

Unknown JSON properties are rejected. Deletion is physical; foreign-key references prevent it. Manufacturer, model year, chassis details and legacy import remain separate extensions.

### List parameters

| Parameter | Default | Accepted values |
|---|---|---|
| `page` | `0` | Integer, 0–10000 |
| `size` | `20` | Integer, 1–100 |
| `sort` | `registrationNumber` | `id`, `registrationNumber`, `capacity`, `active` |
| `direction` | `asc` | `asc`, `desc` |
| `q` | absent | Case-insensitive registration substring, max 100 characters |
| `active` | absent | `true`, `false` |

Search strips surrounding query whitespace and treats `%`, `_` and backslash literally. Sorting adds an ascending ID tie-breaker unless sorting by ID.

```json
{
  "content": [
    { "id": 1, "registrationNumber": "DEMO-123", "capacity": 40, "active": true, "version": 0 }
  ],
  "page": 0,
  "size": 20,
  "totalElements": 1,
  "totalPages": 1
}
```

Empty results have `content: []` and zero totals. Out-of-range pages have empty content but retain the matching totals.

### Errors

Responses use `application/problem+json` with a stable `code`. `VALIDATION_FAILED` adds a `fields` map with codes such as `REQUIRED`, `TOO_LONG`, `FORMAT`, `POSITIVE` and `NON_NEGATIVE`. Internal errors do not expose SQL or rejected input values.

| Status | Code |
|---|---|
| 400 | `VALIDATION_FAILED`, `INVALID_REQUEST` |
| 401 | `AUTHENTICATION_REQUIRED` |
| 403 | `ACCESS_DENIED` |
| 404 | `BUS_NOT_FOUND` |
| 409 | `BUS_REGISTRATION_CONFLICT`, `BUS_VERSION_CONFLICT`, `BUS_IN_USE` |
| 500 | `INTERNAL_ERROR` |

## Security and concurrency

Spring Security enforces ADMIN at both route and service boundaries. [Backend-managed Keycloak login](authentication-setup.md) uses the HttpOnly `JSESSIONID` cookie. Writes require the raw `XSRF-TOKEN` cookie value in `X-XSRF-TOKEN`; Angular HttpClient supplies it for relative API URLs. The CSRF endpoint's masked JSON token is for form logout.

Writes are transactional. PostgreSQL enforces uniqueness; Hibernate `@Version` and optimistic mutation reads protect concurrent updates, including no-op version checks. PUT/DELETE also compare the client's expected version. Changed records increment their version. Reads never increment it; identical PUTs may leave it unchanged. Version conflicts require an explicit reload and review before resubmission. Deletes do not cascade.

## Architecture

- **Backend:** `fleet/api` owns DTOs and HTTP mapping; `fleet/application` owns authorization and transactions; `fleet/persistence` and `fleet/domain` own JPA access and invariants. `shared/api` maps safe errors and OpenAPI metadata. Flyway owns `bus_management.buses`; this feature reuses V1 unchanged.
- **Frontend:** `features/buses` is lazy-loaded and ADMIN-guarded. NgRx Store/Effects/Entity 22.0.1 holds the current server page, query and mutation state. Unsaved form input stays local; credentials and tokens never enter the store. Leaving the page clears feature state and cancels pending work.
- **Requests:** `switchMap` cancels superseded reads; `exhaustMap` permits one in-flight write. Failed writes are never replayed automatically. Successful writes refresh the query, correcting an empty final page after deletion. Uncertain write results require closing and refreshing before retrying.

## Angular screen and state

The Material table provides registration search, status filters, sorting and page sizes 10/20/50/100. Applied queries live in the URL (`q`, `active`, zero-based `page`, `size`, `sort`, `direction`), for example `/buses?q=DEMO&active=true&size=10&sort=capacity&direction=desc`. Missing, invalid or repeated values use safe defaults; generated URLs omit defaults and preserve unrelated parameters/fragments.

The route initializes NgRx before the first request and restores controls/results on reload, copied links and Back/Forward. Search and filters apply on Enter or Search, resetting the page; typing sends no requests. Reset clears search/status and fetches page one, preserving sorting/page size. The refresh icon repeats the applied query without changing draft filters or history. Reapplying an identical query refreshes once without a new history entry. Empty-page corrections replace the URL entry before fetching the corrected page.

`edit=<busId>` selects the editor independently of the list query. Opening, reloading or revisiting that URL fetches the bus's latest saved values, including buses outside the visible page; unsaved edits are discarded on reload. Back closes the editor and Forward reloads it. Cancel/success removes `edit` while preserving filters; cancellation never reloads the list. Invalid/repeated IDs are ignored, missing buses cannot be saved, and failed reads permit an explicit retry.

Create/edit share a validated reactive form; deletion requires confirmation. Conflict reloads explicitly replace unsaved values. API codes drive translated errors. Initial editor reads and reloads can be cancelled; writes disable Cancel/Escape/backdrop dismissal while awaiting confirmation. Closing the dialog cancels its client subscriptions, and mutations are never replayed automatically.

One Material table serves all screen sizes. Below 700 px, compact headings and a three-dot row menu replace the separate desktop edit/delete icon buttons. The UI supports en/de/ar, Arabic RTL, locale-aware pagination and accessible dialogs. Cancel/Escape/backdrop dismissal preserves results, page, scroll and trigger focus without a list request, including return to the mobile menu button. Restored editors focus the loaded form and return to Add bus when no opening button exists. Successful writes refresh once; rows remain visible beneath a scoped loading overlay. Dialog saves/reloads use the same indicator with polite status text and reduced-motion support. Automated axe/keyboard checks do not replace manual screen-reader verification.

The shared `LoadingOverlay` component accepts an active flag, translated label and optional announcement control. It serves table reads, dialog operations and page transitions. The shell follows `Router.currentNavigation`, including guards and lazy page downloads; cancelled or failed navigation clears the overlay. Fast transitions need no artificial delay.

Initial bundle budgets are 800 kB warning / 850 kB error; component-style budgets are unchanged.

## Swagger

`/api/docs` serves Swagger UI; `/api/openapi` and `/api/openapi.yaml` expose the schema. All require an ADMIN application session. Use the existing browser session without a separate Authorize step. Swagger supplies the raw CSRF header; relative server URLs work through both local proxies.

## Validation

From `backend/`, run `./gradlew clean test bootJar`. Frontend commands are in the [README](../README.md#checks). After building stack images, `python3 scripts/smoke-compose.py --browser-tests` verifies a disposable stack without touching development data.

URL-query verification: formatting, lint, browser-test types, 50 unit tests, 152 desktop/mobile browser cases and the production build pass. Browser checks use mocked APIs against the production bundle, covering query/editor restoration, history, loading/errors and existing CRUD, localization and accessibility. Backend and real-stack Compose smoke were not rerun for this frontend-only slice. Hosted checks await publication.
